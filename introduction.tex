\section*{Введение}
\addcontentsline{toc}{section}{Введение}

Одной из центральных задач теории графов является нахождение кратчайших путей в графах, что имеет широкое практическое применение в задачах маршрутизации, логистики, сетевого планирования и моделирования.\hfill

Алгоритм Дейкстры, предложенный Эдсгером Дейкстрой в 1959 году, стал классическим подходом для решения этой задачи на графах с ненулевыми положительными весами рёбер \cite{Dijkstra}.Он позволяет находить кратчайший путь от одной вершины графа до всех остальных, и основой его эффективности является использование структур данных, таких как куча, для оптимизации извлечения минимального значения.\hfill

Обычно в алгоритме Дейкстры используется двоичная куча, обеспечивающая хорошую производительность для стандартных задач.Однако для улучшения производительности при работе с большими графами и для различных практических применений может использоваться D-арная куча (например, 3-куча, 15-куча и др.), позволяющая сократить количество операций по сравнению с двоичной кучей за счёт уменьшения высоты дерева.В частности, 3-куча и 15-куча могут быть полезны для ускорения алгоритма в зависимости от структуры графа и особенностей доступа к памяти.
